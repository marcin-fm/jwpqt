# Bushu/Stroke Lookup

Open **Tools > Stroke/Bushu Lookup** or press `Ctrl+Shift+B` to select the **Stroke/Bushu** tab in the shared lookup window. It searches the same installed Bushu metadata as Bushu Lookup but starts with the radical's own stroke count. This is useful when you can identify a radical shape and know how many strokes that radical has, but do not know its dictionary number.

Set **Radical strokes** from 0 through 17. Zero means no restriction. The radical chooser then displays **Any** and the native Bushu choices for that stroke count. Select a single choice, or leave Any to search by the total-character range alone. **Include variants** controls whether equivalent source radical variants are presented. The Options preference **Hide equivalent Stroke/Bushu and Spahn radical variants** supplies the inverse persisted presentation choice; reduction removes duplicate choices from the selector, not possible characters from a valid metadata search.

Set **Kanji strokes from** and **to** for an inclusive total-stroke range, from 0 through 30. The default upper value is 30. Then choose **Nelson radical**, **Classical radical**, or both. JWPqt keeps at least one matching source selected, and synchronizes those choices with the Bushu tab. A character is eligible when it is in the requested total-stroke interval and its selected Nelson or classical Bushu matches the selected radical. Thus it is distinct from the graphical Radical tab, which combines multiple visible components, and from the simple Bushu tab, which accepts a radical number directly.

Automatic search follows the shared lookup preference. If it is off, changing the radical, variant display, matching source, or range clears old results and waits for **Search**. Clear resets radical-stroke filtering, restores Any as the radical selection, restores total strokes to 0-30, and removes results. The result strip accepts selection, Information, Insert, and Copy actions. A successful manual search focuses that strip; Enter inserts selected results into the active document and Shift+C copies all results.

This tab requires compatible `kanjinfo.dat` metadata; its Bushu chooser uses the native catalog rather than guessing from font outlines. If the metadata is unavailable, JWPqt reports that condition. See [Bushu Lookup](help:IDH_KANJI_BUSHULOOKUP) for the matching systems, [Hadamitzky/Span Lookup](help:IDH_KANJI_HSLOOKUP) for the different Spahn-Hadamitzky catalog, and [Finding Kanji](help:IDH_KANJI_LOOKUP) for shared result actions.
