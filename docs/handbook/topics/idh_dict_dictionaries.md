# Dictionaries

Use **Tools > Manage Dictionaries**, or **Dictionaries** from lookup, to configure the ordered binary `dict.cfg` registry. The manager is staged: add, remove, reorder, enable/disable search, and edit metadata before **Save and Reload** validates the whole candidate and atomically replaces the registry. Cancel changes neither live configuration nor disk. Existing lookup queries, results, and history stay intact; only later searches use the new resource order.

Each row describes a local dictionary: its display name, file path, encoding, name role, classical role, index preference, keep-loaded preference, quiet preference, and search check box. Order determines the normal search order. Removing a row removes only the registry reference, never the data file. The single User row is a mixed, unindexed special resource; it cannot be removed, and close its working-copy editor before changing resources. A checked classical resource still runs only when Classical is enabled; a names-only resource is skipped by No Names.

Supported encodings are EUC-JP, UTF-8, and mixed. Mixed keeps Japanese in the legacy-compatible representation and meanings in the configured default JWP code page captured at reload; it is appropriate for the user resource but should be reviewed before distribution. An indexed resource uses a same-location `.jdx` companion and is fastest. Unindexed/memory resources allow flexible lookup without index limits. Buffered preferences round-trip, but native loading remains bounded rather than recreating the old Win32 streaming implementation. **Keep loaded** can improve repeated searches but may hold a file open. **Quiet** suppresses missing/access diagnostics and is normally inappropriate for a resource you expect to use.

**Defaults** stages CLASSICAL, EDICT, and ENAMDICT while retaining the user entry; optional corpora are never downloaded. The normal package discovers its separately bundled payloads automatically. A configuration directory with `dict.cfg` or explicit resources overrides packaged fallback as a coherent set; incomplete or malformed overrides fail visibly rather than mixing data. In data-free mode configure local legal files. **Runtime Resources** reports loaded sources, invalid records, failures, and skipped classical rows; it is diagnostic, not a guarantee that every optional resource exists.

See [Adding or Editing Dictionaries](help:IDH_DICT_ADDDICT) for file inference, inspection, and saving, and [The Classical Japanese Dictionary](help:IDH_DICT_CLASSICAL) for classical opt-in behavior.
