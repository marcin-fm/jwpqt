# Searching and Results

Press **Search** or Enter in the query field to start lookup; `Esc` aborts it. The result list is replaced only after a successful new search. A zero-match query is a completed search and is remembered, while a failed request leaves the prior list, selection, and history intact. The status area reports diagnostics, match information, and resource failures without forcing a modal interruption.

Results retain canonical dictionary entries separately from their rendered text. **Compact results** can show a headword and comma-separated definitions in one paragraph; the expanded layout shows more separation. That setting, priority grouping, and Advanced separators apply when a search completes. Priority comes from the original terminal `/(P)/` marker before category filtering, and grouping remains within the real search/pass boundary. Classical and user-dictionary entries use the highlight color; Advanced labels use it too, while priority and contingent labels remain ordinary. Labels are copyable display text but cannot be inserted.

Click an entry to select its whole result. `Ctrl`-click or `Ctrl+Space` toggles an entry; Shift-click and Shift+Up/Down extend a range. Plain Up/Down, Home/End, and Page Up/Page Down select the destination row; Ctrl navigation preserves the selected set. `Ctrl+A` selects all results, and a plain Space adds the current row. A new search, Sort, or ordinary within-entry text selection clears the row set.

**Copy** copies selected display text with its exact Unicode spacing. With no row selection, `Ctrl+C` or `Ctrl+Insert` copies the current rendered result row. `Ctrl+E` copies the headword, `Ctrl+R` copies its first reading (or headword), `Ctrl+W` selects the headword, and `Ctrl+Shift+W` selects the full rendered result. **Insert**, Enter, or keypad Enter inserts the whole result rows touched by the selection, in visible order, as one undoable edit in the active document. A plain left double-click inserts the clicked entry, not an older selection. Insertion protects read-only targets, active conversion, invalid Unicode, and surrogate-splitting selections.

**Sort** cycles Reading, Length, Entry, and Definition. Shift cycles backward; Ctrl reverses the current order. It removes grouping labels, preserves the first duplicate's provenance, selects the first entry, and never searches or flushes pending query input. See [Dictionary Options](help:IDH_DICT_OPTIONS) and [Dictionary Codes](help:IDH_DICT_CODES).
