# Creating and Clearing a Kanji List

The Kanji Color List is an ordered canonical collection of supported JIS kanji used by the Color Kanji policy. JWPqt stores it externally as `colkanji.lst`; membership is deduplicated, and the canonical serialized file is sorted by its supported code order. It is not text embedded into the current document. An absent file starts as an empty list, while malformed content is an error rather than a partially accepted list.

Choose **Tools > Make Kanji Color List** to replace the list with the unique supported kanji from the current JWP document. This is the fastest way to create a baseline list from study material. Choose **Append Document to Kanji Color List** to add the current JWP document's supported kanji to the existing membership, preserving earlier members. Both operations are enabled only when a list location is configured, the current document is a JWP document, and no WNN conversion is active. They do not add arbitrary Unicode characters outside the supported color-list range.

Choose **Tools > Add or Remove Kanji** for direct editing. The prompt accepts `K`, `A`, or `J` input modes and uses the shared Insert/Overwrite behavior. JWPqt completes pending kana before validating the entered list text. The command adds or removes each supported character as requested; duplicates are harmless. It validates the proposed change and atomically writes the full list before updating display colors. This avoids the legacy risk of editing a list on screen while persistence has failed.

Choose **View Kanji Color List** to open the current list in a separate Japanese document tab. This is a view of the list, not an in-place replacement of the active work document. It is available only for a configured, nonempty list when conversion is inactive. Use it to inspect membership, then return to Add or Remove for validated list changes rather than assuming edits to the view tab update the external list.

Choose **Clear Kanji Color List** to replace the list with an empty canonical list. It is available only for a configured nonempty list and is blocked during conversion. Clearing changes membership, not the Color Kanji options: a members/nonmembers policy remains selected and will respond to the now-empty list. See [Color Kanji](help:IDH_KANJI_COLORKANJI) for precedence and display, [Color-Kanji Options](help:IDH_KANJI_COLOROPTIONS) for policy settings, and [Count Kanji](help:IDH_KANJI_COUNTKANJI) for filters based on membership.
