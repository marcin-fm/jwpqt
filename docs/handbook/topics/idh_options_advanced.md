# Advanced Options

Advanced Options exposes bounded native capacity and compatibility controls, not unsafe legacy memory tuning. The important adjustable native capacity is **Learned conversion choices**, which controls how many kana-to-kanji preferences are kept. Its permitted range is 10 through 2000 and its default is 200. Reducing it retains the most recent stored choices that fit; increasing it creates empty slots. A loaded conversion resource resizes immediately when Options is accepted. Finish or cancel an active candidate preview before changing the capacity, so cancellation cannot restore an obsolete preference size.

Query-history capacity is also persistent and applies separately to the dictionary, search, and replacement lists. At the default 300-cell capacity each list allows 31 entries and 267 scalars in total. Reducing capacity can remove in-memory entries. If a fuller archive exists, automatic saving pauses until Reload with sufficient capacity or an explicit Save; this prevents a stale or downsized in-memory copy from overwriting information. External creation, deletion, change, or corruption of an archive also blocks stale overwrites. Save As permits recovery into a new file.

Native Japanese undo depth defaults to 50 levels and accepts 3 through 1000; reducing it discards the oldest native undo/redo entries. Unicode editors retain Qt history. Default JWP page margins are 1 inch on all sides, horizontal and portrait; margin controls accept 0..10 inches or 0..25.4 cm when metric display is enabled. Print defaults are justify-ASCII on, header/footer positions 0, 0, 1, and 1, with positions accepted from 0..10 characters or lines. Date/time patterns have capacities of 19 JWP characters (AM/PM 9).

Settings management itself is deliberately conservative. Settings load from `jwpqt.cfg`; Save and optional save-on-exit atomically replace only a valid writable target. Invalid settings are not applied, corrupt startup settings are not automatically replaced, and importing settings overlays known values while retaining unsupported ones. Default Settings resets supported values yet retains unknown fields. Runtime Resources and Options expose retained but unapplied values. This is useful when moving configuration from a legacy source without pretending that every historic implementation detail has a native counterpart.

Several legacy Advanced controls are documented exclusions. Allocation size, Win32 font-cache size, display-font caching, and similar buffer knobs selected implementation strategies of the old Windows application. JWPqt uses portable bounded parsing, rendering, and private-font caches instead, so presenting those old sliders as active performance promises would be inaccurate. Native private font loading has explicit resource bounds and releases its cache when the application closes. If a selected legacy font is malformed or too large, it fails explicitly rather than degrading into an uncontrolled cache setting.

Advanced remains a settings topic, not a utilities interface. The historical JINDEX, KINFO, RINFO, UINFO, and WINFO programs created legacy dictionary and conversion data; they are not controls to run from JWPqt Options. Use Runtime Resources to inspect loaded sources and failures, and consult [Support](help:IDH_SUPPORT_GENERAL) for data and diagnostic boundaries.
