# Acknowledgments

JWPqt recognizes the work that made the JWP, JWPce, and JWPxp lineage possible. The original JWP interface and origin are credited to Stephen Chung. Glenn Rosenthal authored the original JWPce program and documentation from 1997 through 2005. JWPxp modifications remain credited in the preserved source history and release notes. Native Qt port contributions likewise retain their source history.

The application also depends on work represented by separately noticed resources: WNN kana-to-kanji data; EDICT and ENAMDICT Japanese-English data associated with Jim Breen; KANJIDIC-derived character information; SKIP and frequency information; radical and stroke lookup data; Japanese conversion routines; and fonts. Their inclusion in a normal package is not a claim that their authors assigned them to the program GPL. Their individual notices and restrictions remain authoritative.

Qt 6 provides the cross-platform application toolkit. It is dynamically linked and separately licensed. Linux distributions additionally provide system libraries and fonts; Windows and macOS packages deploy the required Qt runtime components. The Web port embeds Noto Sans JP for canvas text and carries the font's OFL with its Web assets.

Use About to reach the GPL and original copyright/data notices in the offline handbook. This topic is a credit summary, not a replacement for those texts. See [Support](help:IDH_SUPPORT_GENERAL) and [What is saved with a JWPce File?](help:IDH_FILE_CONTENTS).
