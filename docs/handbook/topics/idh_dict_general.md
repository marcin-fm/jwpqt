# Dictionary Introduction

Dictionary Search is a modeless lookup tool for the EDICT-family resources configured for JWPqt. It remains open while you read or edit, and inserts into whichever document tab is currently active. Open it with **Tools > Dictionary**, the matching toolbar action, `Ctrl+D`, or `F6`. The lookup window owns its query and result list; opening it does not change the document selection.

The normal noncommercial-data edition installs EDICT and ENAMDICT as separate, unmodified payloads, with their retained notices and redistribution restrictions. They are not GPL program data. CLASSICAL is optional and is not part of the normal bundled payload. A build made with `-DJWPQT_BUNDLE_LEGACY_DATA=OFF` is data-free: configure legal local resources in the dictionary manager before expecting results. JWPqt never downloads a dictionary automatically. Missing, invalid, or skipped resources are reported rather than silently substituted; **Help > Runtime Resources** and the Resources status show what was loaded.

Opening lookup can use a selected first-paragraph span. **Options > Dictionary > Search a document selection** is on by default: when enabled, an actual selection is searched immediately. With no selection, a new lookup may prefill the word under the caret but does not automatically search that fallback. Disable the option to preserve an existing query draft. See [What you can Search for](help:IDH_DICT_SEARCHFOR) and [Dictionary Options](help:IDH_DICT_OPTIONS).

The query field has its own **K**, **A**, and **J** input-mode control. Kanji mode composes romaji to kana; ASCII and JASCII are available without changing the document's input mode. It shares the window's Insert/Overwrite state, resolves pending kana when Search is requested, and rejects invalid input without erasing the draft. Native direct and pattern processing is bounded to the first 100 characters; overlong input is not silently made eligible for contingent retry.

Choose **Search** or press Enter in the query field to replace the result set. A valid zero-match search reports that outcome and remains eligible for history; a failed search preserves the old results and history and shows a nonmodal diagnostic. `Esc` cancels active work. Controls change saved policies but do not discard results or start a search by themselves. Use [Searching and Results](help:IDH_DICT_RESULTS) for selection, copying, and insertion, and [Dictionaries](help:IDH_DICT_DICTIONARIES) to configure resources.
