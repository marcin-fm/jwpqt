# JWPce Features

JWPqt retains the core strengths of the JWP family in a native Qt 6 application. Its document editor supports independent tabs, undo and redo, search and replace, native JWP paragraph formatting, hard page breaks, projects, recent files, and optional session restoration. JWP/JCE, JFC, Unicode, EUC-JP, Shift-JIS, JIS variants, and legacy code-page files are handled with explicit encoding choices and loss checks.

Japanese input has Kanji, ASCII, and full-width JASCII modes. Kanji mode composes desktop romaji into kana. If WNN data is present, a candidate strip previews kana-to-kanji conversion; Space, Shift+Space, or Convert cycles candidates, and Enter or Escape accepts one conversion as one undoable edit. Dictionary and lookup tools can insert selected results into the active compatible document.

Reference features include Japanese-English dictionary search with filtering, patterns and deinflection; editable user dictionaries; Character Information; JIS character tables; and radical, stroke, Bushu, SKIP, Spahn-Hadamitzky, Four Corner, Index, Reading, and code-table workflows. Kanji color lists and count tools remain available.

Desktop ports provide native print and PDF preview with margins, headers/footers, selections, page ranges, colors, and legacy vertical conventions. The offline handbook is searchable and context-sensitive through F1. Toolbars, themes, fonts, colors, line width, history, and clipboard representations are configurable. See [Finding Kanji](help:IDH_KANJI_LOOKUP), [Dictionary Introduction](help:IDH_DICT_GENERAL), and [Printing](help:IDH_PRINT_GENERAL).
