# Introduction

JWPqt 2.02 keeps the familiar purpose of the legacy Options dialog while making its behavior explicit for a native Qt 6 application. Open **Tools > Options** to stage preferences for the application. Nothing becomes effective until you accept the dialog; Cancel leaves the live configuration unchanged. Help from the dialog opens the relevant embedded handbook topic and does not accept or discard staged work. Every Options page scrolls, so its controls remain available on small or high-DPI displays.

The native configuration is stored as `jwpqt.cfg` in the application configuration directory. Its normal location is chosen by Qt for the host platform; use `--config-dir` only when an application-specific override is intended. **Save Settings** writes the supported preference subset by atomic replacement. Optional save-on-exit uses the same safe write path. Invalid values are not applied, a corrupt startup file is not silently overwritten, and a settings save cannot overwrite a file currently open as a document.

**Import Settings** validates supported assignments before applying them. Imported known values overlay the current supported settings. Unknown legacy or future entries are retained rather than guessed at, and the Options dialog and Runtime Resources disclose that they are unapplied. **Default Settings** resets implemented values to their defaults but deliberately retains genuinely unknown entries. This allows a native installation to preserve compatibility information without claiming to implement it. Settings imports and defaults are not a replacement for document Page Layout, which is documented separately.

The application retains the historical breadth of options, but it does not recreate every Win32 mechanism. In particular, legacy font-cache and display-buffer controls selected memory strategies from the old application layer; JWPqt uses a bounded native font engine instead. Other old platform assumptions are likewise replaced explicitly: Qt application locations replace registry setup, portable Qt MIME formats replace private Windows clipboard identifiers, and the host desktop owns input-method state.

Use the topic pages for the individual controls: [General Options](help:IDH_OPTIONS_GENERAL), [Display Options](help:IDH_OPTIONS_DISPLAY), [Font/Format Options](help:IDH_OPTIONS_FONT), [File/Clipboard Options](help:IDH_OPTIONS_FILECLIPBOARD), [Miscellaneous Options](help:IDH_OPTIONS_MISC), [Advanced Options](help:IDH_OPTIONS_ADVANCED), and [Toolbar Customization](help:IDH_OPTIONS_TOOLBAR). Historical localization files and command-line utilities are not native Options pages; they remain relevant only as migration context where a preserved setting or dataset is encountered.
