# Count Kanji

Open **Tools > Count Kanji** with `Ctrl+Shift+K`. Count Kanji is modeless and works from fresh document snapshots. Press **Count** to inspect the current document, or enable **Count all open documents** when more than one document is open. Counting neither changes document text or history nor accepts a conversion preview. Closed tabs disappear from the next snapshot, and edits are reflected on the next Count.

Choose **Include**: **All kanji**, **Exclude kanji color list**, or **Only kanji color list**. These filters use the same external membership list used by Color Kanji. They filter the displayed kanji entries, while the status summary still identifies list-related totals. An absent list is simply empty; malformed list data remains an external resource failure rather than a guessed classification.

Select optional columns for **frequency**, **on readings**, **kun readings**, and **meanings**. Frequency is enabled initially. Readings and meanings require an installed metadata record for the character; JWPqt omits unavailable enrichment instead of inventing it. Each result row starts with its character, followed by enabled data separated into columns. Entries sort by descending occurrence count and then JIS code. A configured result bound can truncate the list; the status line says so.

The status report includes total characters, total kanji, unique kanji, occurrences on the color list, and occurrences off the list. Internally JWPqt also distinguishes hiragana, katakana, ASCII, JASCII, and other characters, so a document's non-kanji content is not miscounted as kanji. “Kanji” here follows the application's JWP character categories and supported JIS text model, including the native JIS kanji range; it is not a universal Unicode-script detector.

Select one or more rows to use **Copy**, **Insert**, or **Information**. Copy preserves selected displayed rows as lines. Insert adds selected displayed rows, separated by newlines, to the active document. Information opens Character Information for the first selected entry. These actions let you turn a frequency report into editable notes without altering the document being counted. Use [Color Kanji](help:IDH_KANJI_COLORKANJI) for the color policy, [Creating and Clearing a Kanji List](help:IDH_KANJI_KANJILIST) for membership changes, and [Character Information](help:IDH_KANJI_CHARINFO) for metadata details.
