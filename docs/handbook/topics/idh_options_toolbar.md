# Toolbar Customization

Open **View > Customize Toolbar** or **Tools > Customize Toolbar** to stage a toolbar layout. The dialog presents the complete native catalog derived from the recovered legacy command inventory. Select a catalog command and Add it after the selected toolbar slot; select a slot to Remove it or Move Up/Move Down. Separator is a reusable catalog item, and commands may repeat. Reset Layout restores the native default order without changing unrelated preferences. Cancel discards all staged toolbar changes and leaves the live toolbar and editor state intact.

The toolbar starts visible. View > Toolbar can hide it when it is not wanted, but a layout itself must contain at least one slot. The source-compatible default stores 39 active slots in a 100-slot layout: 30 commands and 9 separators, including its leading separator and Options command. The customization catalog has 36 commands plus the reusable separator entry. Repeated toolbar buttons invoke the same authoritative menu action and do not create duplicate keyboard shortcuts. Checked and enabled state continues to follow the underlying menu action and loaded resources.

JWPqt extends the legacy layout with native presentation choices. Dock the toolbar at the top, bottom, left, or right; choose whether movement is locked; select 16 through 48 logical-pixel icons; and choose icons-only, text-beside, text-below, or text-only presentation. Floating is intentionally disabled. Docking, visibility, customization, icon size, text style, and lock state persist in normal settings and projects. Imported legacy toolbar IDs and inactive configuration bytes are preserved. Invalid active IDs are rejected before changing the toolbar.

Every command uses bundled scalable SVG art, not a host icon theme or legacy toolbar bitmap. Transparent monochrome symbols follow enabled and disabled palette text colors in light and dark schemes, while the colored application icon retains its own identity. This means changing [Display Options](help:IDH_OPTIONS_DISPLAY) theme behavior recolors toolbar symbols appropriately without changing document content or Undo.

The legacy Windows CE command bar was neither disableable nor configurable, and its PPC variant switched between menu and common buttons. JWPqt does not expose that historical device-specific behavior as a desktop toolbar mode. The native toolbar is a Qt desktop interface whose persisted settings are portable across its supported desktop builds; the Web interface keeps the same Qt surface subject to browser platform limits.
