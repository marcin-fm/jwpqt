# The Classical Japanese Dictionary

The optional CLASSICAL resource serves classical Japanese and is not an introduction to classical grammar. Configure it in the dictionary manager and enable **Classical** in Dictionary options before it participates in lookup. When active, it is searched before normal resources, regardless of its ordinary registry position, and its results use the highlight color. Keep modern EDICT configured too: words still used in modern Japanese may not occur in CLASSICAL. Include name resources when names matter, subject to the name filters. See [Dictionaries](help:IDH_DICT_DICTIONARIES).

Ordinary classical word lookup follows the same query limits, boundaries, selection, Copy, and Insert rules as other resources. Classical entries can carry grammar-specific tags, including `adv-part`, `case-part`, `comb-part`, `conj-part`, `emo-part`, `exc-part`, and `fin-part` for particle roles; `kamiichi`, `kamini`, `shimoichi`, `shimoni`, `yo`, `nahen`, `rahen`, and `Sahen` for verb classes; `ku` and `shiku` for adjectives; and `makura`, `pre`, `post`, and `set phrase` for fixed expressions and affixes. These are source annotations; see [Dictionary Codes](help:IDH_DICT_CODES).

The configured data may contain dedicated jodoushi, particle, prefix, postfix, and other grammatical entries. Results can therefore show multiple usages and, for conjugated auxiliaries, bracketed forms corresponding to the six traditional bases: mizenkei, renyoukei, shuushikei, rentaikei, izenkei, and meireikei. A modern Japanese equivalent may appear in braces. Search the observed form with the ordinary native query and resolve competing analyses from context. Do not rely on an undocumented legacy grammar-prefix convention: in the native pattern language `#` means one kanji, as described in [What you can Search for](help:IDH_DICT_SEARCHFOR).

The recovered native classical loader accepts valid records while reporting skipped malformed rows. Runtime Resources currently distinguishes this bounded recovery from ordinary EDICT, ENAMDICT, and user-dictionary loading, which reject malformed data rather than quietly repairing it. A missing classical file is optional until enabled; its availability is visible in resource diagnostics. Data-free builds require you to configure a lawful local classical file if you need it.

User Dictionary entries can be prepared for external classical projects, but JWPqt does not submit them. Follow the same caution as EDICT-style contributions: plain verb forms, accurate kana and kanji, no guessed characters, compatible grammar conventions, and no copyrighted copied definitions. Use [Adding or Editing Entries](help:IDH_DICT_USEREDIT) for local record editing and [Dictionary Options](help:IDH_DICT_OPTIONS) for enabling Classical.
