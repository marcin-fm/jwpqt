# Character Information

Open **Tools > Character Information** or press `Ctrl+I` to inspect the character at the caret or the first character of the selection. A right-click character menu can open the same viewer; Shift-right-click opens it directly. The latter uses the exact character that was clicked and does not move the document selection. Character Information is modeless: each request opens an independent window, so earlier viewers remain available while you inspect another character, a reading, or a result.

The window shows a scalable large glyph, Type, JIS and EUC-JP values where applicable, Shift-JIS, and Unicode. With installed kanji metadata it also shows strokes, grade, Nelson and classical Bushu, Nelson/Haig, Halpern/SKIP, Spahn, Four Corners, Morohashi, pinyin, Korean, frequency, and the available dictionary-reference fields. The configurable reference set includes Henshall, Gakken, Heisig, O'Neill, De Roo, Kanji Learners, Read/Write Japanese, Tuttle Kanji Cards, The Kanji Way, Kanji in Context, Japanese for Busy People, and Compact Kanji Guide. Bushu and cross-references remain available independently. More Info includes later configured fields and references such as alternate indexes, JIS X 0208 or X 0212 references, and alternate SKIP classifications.

Meanings, on-yomi, kun-yomi, and nanori appear in separate labelled sections when metadata supplies them. Select text in this pane or More Info and use **Insert to File** to insert it into the currently active document. Double-click the large glyph to insert that character. **From Clipboard** changes only this viewer to the first displayable clipboard character. Kana instead lists accepted romaji spellings; supported Greek and Cyrillic characters have their own names.

Use **Tools > Character Info Setup** to order the 26 fields, place Blank spacers, choose compact readings, and hide or show reading headings. All configured rows appear in the main panel; rows 14-26 also appear in More Info. Compact form joins meanings with comma-space and kana readings with Japanese commas. Changes update existing viewers after they are accepted. JWPqt deliberately keeps the legacy single-dialog preference unapplied: viewers remain independent.

Without `kanjinfo.dat`, or when a particular record is unavailable or corrupt, the viewer still shows the printable character and its basic codes, with a diagnostic. It does not infer missing readings, references, or indexes. See also [Alternate kanjinfo.dat Files](help:IDH_KANJI_KANJINFO), [JIS Character Table and Selecting Characters](help:IDH_KANJI_JISTABLE), and [Finding Kanji](help:IDH_KANJI_LOOKUP).
