# Actually Printing Something

Use File > Print on a native desktop document to open the protected system output workflow. The job is based on a frozen document, formatting, selection, metadata, font, and options snapshot. Editing or switching tabs after the dialog opens cannot change that job. The print workflow supports the entire document, exact selected text, page ranges, reverse order, collated or uncollated copies, and cancellation. Page ranges may be contiguous or disjoint. See [Printing](help:IDH_PRINT_GENERAL) and [Page Breaks and Formatting](help:IDH_PRINT_PAGEBREAK).

Selected text is not implemented by drawing the full document and hiding parts with a clip. Its excluded text is omitted from the PDF stream. Page-range output similarly renders the selected pages. The renderer validates page/range geometry and bounds paper size, page counts, format/run counts, copy count, and rendering work. Invalid input or an oversized job reports an error rather than producing silently truncated output. The final cancellation checkpoint is meaningful; after pages have reached a physical printer, however, cancellation cannot recall them. See [Printing and Color Kanji](help:IDH_PRINT_COLORKANJI).

PDF output is written to a temporary file beside the chosen destination and atomically published only after a successful, uncancelled job. A cancellation, invalid geometry/range, or attempt to print into a destination currently opened as a document cannot destroy a previous PDF. Application settings, history files, and the current project are also protected as output targets. PDF verification is the native port's accepted print gate, while physical printer hardware is waived. See [Temporary Files and System Failures](help:IDH_FILE_TEMP).

Printer Setup initializes physical margins and orientation and applies accepted JWP layout changes as one undoable change to the original document. Preview provides page navigation, zoom, and a Print action that uses the same protected output path. Preview by itself never writes the remembered PDF destination. In a Web browser neither Print nor Print Preview is available because Qt WebAssembly lacks PrintSupport; download a document and use an external browser/host workflow if printing is needed.
