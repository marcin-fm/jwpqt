# Reading Lookup

Open **Tools > Reading Lookup** with `Ctrl+Shift+R`. This is a separate modeless window because its query is text rather than a shared code-tab criterion. Choose a **Type**, enter **Reading or text**, optionally limit **Strokes** with an inclusive range from 0 to 30, and press **Search**. Unlike automatic code-tab searches, Reading Lookup is explicit: edits do not replace the previous report until Search succeeds.

Available types are **On-yomi**, **Kun-yomi**, **On-yomi or kun-yomi**, **Meaning**, **Nanori**, **Pinyin**, and **Korean**. Metadata controls whether Nanori, Pinyin, and Korean appear. JWPqt selects its local input mode from the type: reading types use Japanese kana input; Meaning, Pinyin, and Korean use ASCII. An existing query keeps its own local input mode when preferences change, while a new window initializes for its selected type.

For on-yomi and kun-yomi types, enter kana. A hyphen/long-vowel mark and parenthesized okurigana notation are supported when forming a precise reading. **Flexible kun-yomi matching** applies only to Kun-yomi and On-yomi or kun-yomi. It permits appropriate matching around okurigana and long-vowel notation; leave it off for exact stored reading structure. **Allow partial-word matches** applies only to Meaning. When selected, a text fragment can occur within an English meaning; when clear, matching follows complete stored word boundaries. These options persist in Options > Kanji Lookup.

Pinyin and Korean searches use single-byte roman text and compare without ASCII case differences. Pinyin accepts tonal characters or a tone digit immediately following a vowel; digits 1-4 map to the corresponding tone, and 0/4-style unmarked input remains plain as defined by the native search. Do not use this as an assertion that a data-free installation includes pinyin or Korean: unavailable types are omitted.

**Clear** empties the query, restores strokes to 0-30, removes results, and focuses the query. Results support selection, Information, Insert, and Copy. Enter inserts selected characters into the active document; Shift+C copies all matches. The status line identifies truncation when a configured result bound is reached. See [Character Information](help:IDH_KANJI_CHARINFO) for examining readings, [Alternate kanjinfo.dat Files](help:IDH_KANJI_KANJINFO) for availability, and [Finding Kanji](help:IDH_KANJI_LOOKUP) for shared result keys.
