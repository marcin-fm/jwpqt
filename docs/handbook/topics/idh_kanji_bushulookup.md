# Bushu Lookup

Open **Tools > Bushu Lookup** or press `Ctrl+Shift+L` to select the **Bushu** tab. Bushu is a dictionary radical classification, unlike graphical Radical Lookup's multiple-component intersection. Choose a radical from the grid or type its radical number. The selected grid item updates the number field and supplies a radical-stroke estimate for its spinner. The tab then matches characters by the selected radical number and total character stroke count.

The grid is grouped by radical stroke count and may include recovered variant glyphs. It identifies each selectable item with its Bushu number and radical-stroke count. The **Radical number** and **Stroke count** fields both accept **Any**. The stroke arrows cycle Any, the selected radical's minimum/estimate, values through 30, and Any again; direct numeric entry remains available. Choose an exact total stroke count when you know it, or use Any while first narrowing by radical.

Two matching systems are available: **Nelson radical** and **Classical radical**. At least one stays enabled. Selecting both returns a character if either system matches the requested radical. Most characters share the same assignment, but some do not; use the source appropriate to the book or classification you are following. JWPqt applies recovered normalization for known equivalent source radical numbers, so the displayed choice follows the native catalog rather than requiring a legacy platform-specific workaround.

The search is driven by installed `kanjinfo.dat`; missing metadata cannot be reconstructed from glyph shape. With Automatic search enabled, changes schedule a search. With it disabled, the prior result strip clears until you press **Search**. **Clear** returns radical and stroke number to Any and clears results, but leaves the persisted Nelson/classical preference ready for the next query. Changes to these source choices are synchronized with the Stroke/Bushu tab and are saved under Options > Kanji Lookup.

Use result actions only after checking the status count: select one match for **Information**, or select one or more for **Insert** or **Copy**. Insert targets the active document. Result shortcuts are described in [Finding Kanji](help:IDH_KANJI_LOOKUP). For selecting one radical after first choosing its radical stroke count, use [Bushu/Stroke Lookup](help:IDH_KANJI_BSLOOKUP). For arbitrary graphical components instead of dictionary classification, use [Radical Lookup](help:IDH_KANJI_RADLOOKUP).
