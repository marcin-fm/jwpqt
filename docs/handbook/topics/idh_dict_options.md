# Dictionary Options

Open **Options > Dictionary** from application settings or use **Options** in the lookup window. The page stages policy changes; accepting them updates an open lookup without searching, flushing pending kana, changing its query, or clearing its results or selection. Cancel also leaves current lookup state intact. Manual lookup toggles update the saved preferences, and supported dictionary choices persist through application settings and projects.

**Search a document selection** defaults on. **Compact results** controls the next successful result layout. **Begin With**, **End With**, **Full ASCII**, and **JASCII to ASCII** define direct matching; consult [Limiting the Search](help:IDH_DICT_LIMITS). **Priority entries first**, a priority separator, and an Advanced separator govern result presentation only after a successful search. Existing results retain their completed layout even if a preference changes or a later search fails.

Advanced settings are **Advanced**, **Always Search**, **Show All**, **I-adjectives**, and the direct/adaptive separator mark. They configure bounded adaptive deinflection rather than wildcard syntax. **Contingent** controls the eligible failed-exact Japanese retry. **Link Advanced with exclusion of personal and place names** is off by default; when enabled it applies only to subsequent user toggles, not silently imported combinations. **No Names** represents both personal and place exclusions and can show a mixed state. See [Advanced Dictionary Searches](help:IDH_DICT_ADVANCED).

The **Exclude tagged senses** list exposes the 21 supported exact source tags. It filters individual tagged senses before result limits and fallback paths, while unknown mask bits are retained but unapplied. The native behavior deliberately does not classify definitions semantically. See [Dictionary Codes](help:IDH_DICT_CODES).

**From Clipboard** explicitly searches the first paragraph of clipboard text. **Monitor Clipboard** is off by default and watches only future external copies while lookup is visible. Opening lookup or enabling monitoring never consumes an old clipboard value. Queued requests coalesce and are cancelled by editing, selection change, hiding, closing, or disabling; application-owned copies and modal interactions are ignored. On X11, visible lookup windows also poll external ownership changes. Successful clipboard searches can enter persisted query history, so enable monitoring only intentionally.

**History** recalls text without searching. Completed searches, including no-match queries, are remembered; duplicates move to the front. The default legacy-sized dictionary budget is 31 entries and 267 Unicode scalars. Options > History can set each history to 0 through 30000 storage cells and control saving on exit. See [Dictionary Introduction](help:IDH_DICT_GENERAL) and [Searching and Results](help:IDH_DICT_RESULTS).
