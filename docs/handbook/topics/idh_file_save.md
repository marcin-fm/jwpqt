# Saving Files

File > Save writes the current document to its current pathname and representation. For an unnamed document, saving requires a name and format choice, effectively using Save As. Save All visits every document, including unnamed documents, and stops on the first cancellation or error without discarding unprocessed documents. Before publishing any output, JWPqt completes pending input/conversion and validates the selected encoding and destination. An unsupported character or invalid encoding fails before the destination is changed. See [Japanese Encoding Systems](help:IDH_FILE_ENCODING) and [Backup Files](help:IDH_FILE_BACKUP).

Save As intentionally changes the live document's pathname and/or representation after a successful write. It offers Normal JWPce (`.jce`), JWP (`.jwp`), and the supported text formats regardless of editing engine. Moving to text may lose structured JWP data such as paragraph/page layout, summary metadata, headers, footers, and hard page breaks; the application asks for the required loss confirmation. Save As may not overwrite a pathname belonging to another open document. Existing `.jwp` files retain that extension, while a new native Japanese document defaults to `.jce`. See [File Types](help:IDH_FILE_TYPES) and [What is saved with a JWPce File?](help:IDH_FILE_CONTENTS).

Export Copy is for a secondary file. It validates and writes another representation without changing the live document path, saved baseline, modified state, or undo history. It cannot overwrite the current source or another open document's path. Use it when a converted or text-only copy is needed while editing must continue against the original native document. See [Duplicate Files](help:IDH_FILE_DUPLICATE).

Native saves are atomic. PDF output uses a similarly protected temporary-and-publish workflow, but printing is a separate output command. The optional previous-version backup preserves the old destination bytes before publication; failures creating that backup leave the document and old backup intact. In the Web port, Save and Save As update the browser working copy and download the exact encoded bytes instead of assigning a general desktop pathname. See [Temporary Files and System Failures](help:IDH_FILE_TEMP) and [Actually Printing Something](help:IDH_PRINT_PRINTING).
