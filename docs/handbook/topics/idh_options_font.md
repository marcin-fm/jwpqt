# Font/Format Options

Font/Format Options combines JWP layout rules with native font-role selection. The two margin-relaxation controls allow the original closing-punctuation and small-kana sets to hang one character beyond a full Japanese line. They apply to JWP screen and print layout, not imported text containers. Turning either control off restores ordinary wrapping for its character set without editing the document.

Japanese roles are System, Edit, List, KanjiBar, File, Big, Table, Bitmap, and Print. Blank screen-role families inherit natively, ordinary screen sizes default to 16 px and accept 1 through 1024 px, Big's stored default is 48 px but it fits its pane, and Table is fixed at 16 logical pixels. The Print role defaults to Automatic at 12.0 pt and accepts 1.0 through 144.0 pt (stored in tenths of a point). Role inheritance remains important: missing families inherit the parent role's family and size, while the requested unavailable name is retained and reported through diagnostics. System/Edit/List/KanjiBar/File/Big/Table and Bitmap are not desktop menu fonts. Print is a separate physical role. Ctrl+MouseWheel over an active document changes File by one logical pixel per notch, from 1 through 1024; the first adjustment makes an inherited File role explicit at its current rendered size. It updates all open documents without changing query/list fonts, scrolling, text, selection, history, or modified state.

Font selectors normally show Japanese and printer families that advertise Japanese support. **Show all installed families** exposes all public system families when needed; it does not alter a selected family or manually entered name until Options is accepted. The ASCII selector is always complete. A separate ASCII face is matched to the Japanese role height and cannot take over Japanese glyphs even if the source family contains CJK characters. ASCII defaults to the native family with stored size 0 and Automatic on; legacy `ASCII.Size` and `ASCII.Auto` values are retained but do not override that matched height.

You may enter a legacy `.f00` file in place of a font family, including for Print. Relative paths resolve from the settings directory; absolute paths are accepted. JWPqt decodes packed or holey JIS bitmaps into bounded private pixel-outline faces. Screen roles use original height, Big fits its pane, Table stays 16 px, and Print keeps its physical point size. Invalid or unavailable screen fonts fall back through inheritance with a diagnostic; an invalid explicit print font fails before output is written. Files are neither modified nor installed system-wide.

For role use and source formats, see [Fonts Introduction](help:IDH_FONTS_INTRO), [Choosing an ASCII Font](help:IDH_FONTS_ASCII), [Choosing a Japanese Display Font](help:IDH_FONTS_DISPLAY), and [Choosing a Japanese Printer Font](help:IDH_FONTS_PRINTER). Clipboard image font behavior is covered in [File/Clipboard Options](help:IDH_OPTIONS_FILECLIPBOARD).
