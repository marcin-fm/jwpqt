# Future Releases

JWPqt 2.01 is the current released native Qt 6 continuation of JWPxp 1.67. It preserves JWP/JCE compatibility boundaries while replacing the Win32 application layer with portable C++ and Qt implementations for Linux, Windows, macOS, and WebAssembly. Its release policy is evidence-based: recovered behavior is either implemented and tested natively or documented as a platform replacement or exclusion. Newly recovered behavior requires an independent fixture-backed change; it is not silently implied by an old menu item, settings key, or help topic.

The maintained delivery policy builds Linux, Windows, macOS, and WebAssembly artifacts through GitHub Actions on demand and for release tags. Tagged builds publish their artifacts. Linux is a dynamically linked archive requiring compatible system Qt 6 components, C++ libraries, and Japanese fonts; Windows and macOS packages use deployed Qt support; WebAssembly is a static-site build. The Web build uses browser upload/download and IndexedDB persistence. Browser security prevents JPR referenced-file workspaces, and Qt WebAssembly lacks PrintSupport, so those commands remain visibly unavailable rather than being simulated.

The release verification boundary includes GCC and Clang ASAN/UBSAN suites, data-free configuration, package extraction and installed-runtime checks, exact Qt 6.8.3 and Emscripten 3.1.56 WebAssembly build/smoke tests, workflow validation, and license/data inventory checks. Native PDF text, pagination, rendering, ranges, cancellation, and atomic replacement are the printing acceptance gate; physical-printer hardware testing is not required. These facts define tested scope, not a guarantee of pixel-identical Win32 raster output on every desktop or printer backend.

Packaging keeps program and data obligations separate. Native source is GPL-2.0-or-later; binary redistribution requires corresponding source and retained notices. Normal artifacts carry separately licensed noncommercial data as unmodified payloads, while data-free builds omit restricted payloads. The Web deployment includes matching corresponding source and its embedded Noto Sans JP OFL. Source packages exclude Git metadata and local assistant caches.

No future feature list or schedule is promised by the 2.01 source materials. Historical JWPce ideas such as dictionary server mode, advanced searches, font attributes, grammar dictionaries, and furigana are historical context, not a JWPqt release commitment. Likewise, legacy localization DLL workflows are historical Windows resource migration information; native Qt source and embedded handbook delivery define the current interface. For present support and data licensing, see [Support](help:IDH_SUPPORT_GENERAL) and [Dictionary Support](help:IDH_SUPPORT_DICTIONARY).
