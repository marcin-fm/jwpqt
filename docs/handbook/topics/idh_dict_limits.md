# Limiting the Search

Use **Begin With** and **End With** to require word boundaries around a direct query. Begin With starts enabled, matching the legacy default. Begin With matches a query at the start of a word; End With matches it at the end; selecting both restricts a match to the complete word. They are useful for reducing broad kanji or definition searches. Because the Japanese index is organized around the beginning of kana entries, kana lookup effectively has Begin With behavior even if its checkbox is cleared.

**No Names** excludes both personal and place-name categories. Its check state can be mixed when the two category settings differ; clicking it sets both together. Name filtering applies not only to an optional name dictionary pass but also to tagged name records in ordinary resources. **Names** is a temporary search action that includes both categories, turns off Advanced and Contingent retries for that request, and leaves the stored policy unchanged. Classical resources are separately opt-in; see [The Classical Japanese Dictionary](help:IDH_DICT_CLASSICAL).

For ASCII definitions, **Full ASCII** makes the selected boundaries apply to the complete definition rather than to an individual word within it. For example, a short definition term can otherwise find occurrences in longer phrases. **JASCII to ASCII** normalizes full-width ASCII query text before matching. Both controls affect subsequent matching; checking or clearing one preserves the completed list.

**Exclude Tagged Senses** contains all 21 legacy categories: `vulg`, `X`, `col`, `m-sl`, `sl`, `MA`, `id`, `arch`, `obs`, `obsc`, `ok`, `abbr`, `fam`, `pol`, `hum`, `hon`, `fem`, `male`, `pref`, `suf`, and `oK`. The filters compare exact, case-sensitive source tags, not words that merely look like a category. A mixed recognized group retains its allowed senses; an unrecognized tag stops filtering the rest of that group. Filtering occurs before accepted-result limits and fallback decisions, including pattern, adaptive, contingent, and optional-name passes. Unknown persisted mask bits are retained and disclosed but are not applied.

Limits interact with [Advanced Dictionary Searches](help:IDH_DICT_ADVANCED): adaptive candidates still obey boundaries and exclusions. Contingent search requires Begin With and End With and only retries an eligible failed exact Japanese query. Malformed or unsupported queries keep the previous query and results; overlong direct or pattern input is bounded by the native 100-character limit instead of being eligible for contingent retry. The status of a completed search distinguishes matches from entries rejected by active limits, so broaden settings deliberately rather than assuming an unavailable dictionary.
