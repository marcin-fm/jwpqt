# Miscellaneous Options

Miscellaneous Options gathers persistent behavior that does not belong to document layout, fonts, or resource installation. Its main native controls are document/query/list/candidate presentation policies, default JWP code-page selection, dictionary search policies, exit/recent-file/query-history persistence, and history capacity. Options changes are staged: accepting updates the relevant live interface without rewriting document text or clearing its Undo history; cancelling preserves effective preferences.

The result-list insertion policy starts enabled. With it enabled, complete rows inserted from dictionary, accumulated results, count, or user-dictionary views become distinct paragraphs, including the terminating paragraph after the final row. Disabling it produces compact insertion: eligible ASCII boundaries receive a tab, while Japanese or already-spaced boundaries join directly. Character-by-character insertion from information and kanji lookup controls is unaffected. The complete insertion remains one Undo operation in native Japanese and unrestricted Unicode documents.

Dictionary options are shared by lookup windows and persist through normal settings and projects. They include search boundaries, adaptive searching, personal/place-name and classical dictionary choices, and the source-compatible exclusion mask. Changing an accepted option updates an open lookup without starting a search, flushing pending kana, or replacing results and selection. Unknown exclusion bits remain retained and disclosed instead of being treated as implemented. Search a document selection starts enabled: opening lookup searches the selected first-paragraph span without altering the document. With no selection, a new lookup can still prefill the word under the cursor without searching it.

The history area governs independent dictionary, Find, and Replace lists. Its default source-sized capacity is 300 storage cells, permitting up to 31 entries and 267 Unicode scalars per history. Oversized queries can still be searched but are not silently truncated into history. Query history resides in `query-history.bin`; automatic saving can be disabled without deleting an existing archive. The Tools > Query History commands Save, Save As, Reload, Import, and Clear are the native management path. Legacy `JWPxp.his` import needs its original capacity and code page because the file does not identify them; it never rewrites the source archive or imports its unrelated path tail.

Default lookup settings are automatic selection search on, rare kanji last on, Nelson and classical radical matching on, flexible kun-yomi on, partial meanings and SKIP miscodes off, reduced radical choices off, and rare-radical deemphasis on. Default index type is 0 and reading type is 2; accepted index and reading selections are 0..20 and 0..6. Dictionary defaults are beginning-match on, end-match off, personal/place names and classical dictionaries off, advanced search off, advanced inflected search on, keep-searching and I-adjectives off/on respectively, full-ASCII and JASCII matching off, contingent search and clipboard monitoring off, automatic search on, compact results off, priority-first/priority-separator/advanced-separator on, linked advanced names off, and category exclusions empty.

Historical Character Information, Color Kanji, and Windows CE-specific controls informed the older miscellaneous page. JWPqt preserves relevant native display policies but does not recreate obsolete device UI.
