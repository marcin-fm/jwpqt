# Finding Kanji

JWPqt provides one modeless Kanji Lookup window with eight shared tabs: **Radical**, **Stroke Count**, **Bushu**, **Stroke/Bushu**, **SKIP**, **Spahn-Hadamitzky**, **Four corner**, and **Index**. The Tools menu opens the appropriate tab directly. **Reading Lookup** and the **JIS Table** are separate modeless tools. Document right-click menus expose the same lookup actions, with the same command state as the main menu.

Enter criteria on the selected tab and press **Search** where required. The code tabs can use debounced **Automatic search**; that preference is shared with Radical and Stroke Count. When automatic search is off, changing criteria clears old results so they cannot be mistaken for the new query. **Clear** resets the selected tab's criteria, cancels pending automatic work, and clears results. Reading and Index Lookup intentionally remain explicit searches and keep their last report until a successful new Search.

The result strip is a horizontal list of matching characters. Select one or more results and choose **Information**, **Insert**, or **Copy**. Insert goes to the currently active document, not necessarily the document that opened the lookup. Information requires a single selected character and opens Character Information. Copy places selected characters on the clipboard in result order. Shift-click **Copy**, Shift+Space while Copy has focus, or Shift+C copies all results without changing selection. Use the explicit **Information** button or `I`/`F23` for information; double-clicking a lookup result has no documented result action.

Result-strip keys are consistent for radical, code, and reading searches: Enter inserts the selected result; `I` or `F23` opens information; `F4` closes the lookup; `F2` or period moves forward and `F3` or comma moves backward. Ctrl with left/right movement advances five characters. `C` or `Ctrl+C` copies selection. Standard selection and navigation keys continue to work. A successful manual search focuses its results; the query field retains its local Japanese input handling.

**Tools > Options > Kanji Lookup** saves automatic search, rare-kanji ordering, Bushu sources, flexible kun matching, partial meanings, SKIP miscodes, default Index and Reading types, equivalent-radical reduction, and rare-radical dimming. Applying settings preserves pending queries, selection, and results; it does not start a search. Installed metadata constrains factual availability. Continue with [Radical Lookup](help:IDH_KANJI_RADLOOKUP), [Reading Lookup](help:IDH_KANJI_READLOOKUP), or [JIS Character Table and Selecting Characters](help:IDH_KANJI_JISTABLE).
