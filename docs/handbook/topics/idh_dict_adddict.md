# Adding or Editing Dictionaries

In **Tools > Manage Dictionaries**, choose **Add** to create a staged resource definition or **Edit** to modify the selected one. You can also drop one or more local files onto the manager. Browse selects an exact local file. Relative paths are resolved from the directory containing `dict.cfg`, not from JWPqt's working directory. The manager changes registry entries only; removing or replacing an entry never deletes its source files.

Use **Detect** to apply bounded sample inference to the current path, or Browse/drag-and-drop to infer it for a newly selected file. Inference reads at most 2,048 bytes, uses the first slash-delimited description as a proposed name, and enables a companion `.jdx` when present. Detect asks before replacing an existing description and defaults to **No**. If you decline, the old description remains while the other inferred path, encoding, and index fields are applied. Structurally ambiguous bytes can still require you to select EUC-JP, UTF-8, or mixed explicitly.

Set a descriptive display name, path, encoding, and search type deliberately. Indexed means a valid companion index is required; memory/unindexed provides flexible non-index lookup; buffered is stored as a preference but uses the bounded native loader. Mark whether the resource has no names, has names, or contains names only. Mark **Classical Dictionary** only for the special classical record format. **Search this Dictionary** merely makes a row eligible: No Names and Classical opt-in can still skip it. **Keep Dictionary Open** may reduce repeated open cost but can lock the file. **Quiet Handling of Errors** suppresses missing/access messages and should be reserved for genuinely optional deployment layouts.

**Inspect** validates the selected data and any requested index and reports a record count or an error. Classical recovery can report valid records plus skipped malformed rows; ordinary indexed EDICT/ENAMDICT and editable user dictionaries do not use malformed-row recovery. Review inspection errors before saving. Resource-limit violations are fatal. Unavailable checked resources require the explicit allow checkbox during Save and Reload, leaving diagnostics visible afterward.

Save and Reload checks a complete candidate before atomic registry replacement. If another process changes, deletes, or creates the registry while the manager is open, saving fails rather than overwriting it; cancel and reopen to review the newer file. An old ANSI registry needs an explicitly chosen original Windows code page for staged Unicode conversion. Application state, documents, data files, and indexes cannot be used as registry output targets. See [Dictionaries](help:IDH_DICT_DICTIONARIES) and [User Dictionary](help:IDH_DICT_USERDICT).
