# Closing Files

File > Close removes only the current tab. Each tab has independent text, selection, format, and undo history, so closing one document does not close or alter the others. A modified document receives the normal save/discard/cancel decision before its tab can disappear. Save writes it, Discard closes without publishing its unsaved edits, and Cancel leaves the tab open. Close All and Exit collect the required decisions for every modified document before discarding any part of the workspace; they do not begin by closing a subset and then encounter a later cancellation. See [The Exit Command](help:IDH_FILE_EXIT) and [Saving Files](help:IDH_FILE_SAVE).

Closing the last tab normally asks whether to exit. Choosing No leaves a clean unnamed Japanese document in the window, but it does not restore any edits that were already discarded during the close. Settings can disable that confirmation, and another setting can make the window close button close only the active file. Ctrl-close forces file close, while Alt-close forces application exit. Explicit Quit always uses the whole-workspace save checks. See [Creating a New File](help:IDH_FILE_NEW) and [The Exit Command](help:IDH_FILE_EXIT).

Close is also relevant to duplicate copies. Two independently open tabs for one path do not share modified state. Before closing or saving them, decide which content is authoritative; the application prevents Save As and Export Copy from overwriting a path owned by another open document, but independently saving two copies to their shared original path remains a user-visible conflict to avoid. Activating the existing document is generally safer than keeping a duplicate. See [Duplicate Files](help:IDH_FILE_DUPLICATE).

On the desktop, closing after the opt-in named-session feature is enabled records only the currently open named file references, after save/discard checks. Unnamed buffers and unsaved text are never serialized to `last-session.jpr`. On the Web port, tabs and browser-owned working copies may persist through IndexedDB, but clearing site data removes them; that is not an alternative to saving/downloads.
