# Hadamitzky/Span Lookup

JWPqt names this native tab **Spahn-Hadamitzky**, preserving the legacy Hadamitzky/Span topic and its reference system. Open **Tools > Spahn-Hadamitzky Lookup** with `Ctrl+Alt+H`. The tab searches the installed extended metadata by the Spahn-Hadamitzky radical classification rather than by Nelson or classical Bushu. It therefore needs a data set that supplies those extended records.

The searchable components are **Radical strokes**, **Radical**, **Other strokes**, and **Kanji index**. Each accepts **Any** or an exact native value. The supported ranges are radical strokes 0-11, radical code 0-19, other strokes 0-26, and index 0-47. The radical code is the displayed letter sequence: `a=0`, `b=1`, through `k=10`, then `m=12` through `t=19`. Select a radical-stroke count to populate the horizontal radical chooser, then click the appropriate glyph; the tab copies that choice's stroke count and radical value into the fields. You may also type values directly.

**Show variants** controls the recovered Spahn radical chooser. When enabled it presents the source variants; when disabled it presents canonical choices only. Its setting is synchronized conceptually with the Options choice that hides equivalent Stroke/Bushu and Spahn radical variants. This affects selection display and does not claim that omitted variant images make a character unsearchable. The native chooser uses recovered raster radical artwork, whereas its values and results come from metadata.

Enter as much of the classification as you know and press **Search**, or leave Automatic search enabled to run after changes. With automatic search off, changed criteria clear stale results. **Clear** restores all four value fields to Any, stops pending work, and clears matches. Search candidates must have extended Spahn information; records without it are excluded, not guessed. The result strip labels standard primary results and supports Information, Insert, Copy, and the shared keyboard actions.

The Character Information field named **Spahn** displays a complete available code and paired Kanji & Kana index when present, which can be used to verify your query. If no extended metadata is installed, JWPqt reports that rather than exposing a false source list. See [Index Lookup](help:IDH_KANJI_INDEXLOOKUP) for direct reference-number lookup, [Bushu/Stroke Lookup](help:IDH_KANJI_BSLOOKUP) for Bushu/stroke lookup, and [Finding Kanji](help:IDH_KANJI_LOOKUP) for shared actions.
