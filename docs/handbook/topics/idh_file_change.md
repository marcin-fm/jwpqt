# Changing the Current File

JWPqt is a multi-document editor in which each tab owns its own document, cursor, selection, encoding, scroll position, and undo history. New and Open add or activate documents without replacing unrelated open tabs. The active tab is the current file for editing, saving, printing, page-layout changes, and commands that operate on a document. Window navigation provides Next File and Previous File, and Window > Files presents the open documents for direct selection. The recovered shortcuts are Ctrl+Tab or Ctrl+PageDown for the next file and Ctrl+Shift+Tab or Ctrl+PageUp for the previous file. Alt+W opens the file list. See [Opening an Existing File](help:IDH_FILE_OPEN) and [Closing Files](help:IDH_FILE_CLOSE).

Changing tabs does not merge document states. Each tab keeps its own representation and saved baseline, so moving from a UTF-16 text file to a JWP document does not convert either one. A modeless dictionary or Character Information window follows the currently active document for insertion, even if the document from which the tool was first opened has since closed. This is an active-document rule, not an attempt to retain a hidden old tab. See [File Types](help:IDH_FILE_TYPES).

If an Open request names a path already held by a tab, the duplicate-file policy decides whether to activate the existing document, reload it, or make an independent copy. Command-line and replacement-oriented interfaces use the existing tab deterministically rather than showing a duplicate prompt. Reopening a recent file likewise activates an existing tab when appropriate and retains the stored format/encoding rather than re-detecting it. See [Duplicate Files](help:IDH_FILE_DUPLICATE) and [Opening the Same File Again](help:IDH_FILE_REVERT).

The browser port uses the same tab concept for its uploaded working copies, but it has no general local-path workspace. Open stages an upload in browser storage, and save later downloads encoded bytes. Browser-owned copies and preferences can persist in IndexedDB, but browser JPR project commands are unavailable. Therefore, change files there through the tabs and uploads, not by expecting desktop filesystem references or project switching.
