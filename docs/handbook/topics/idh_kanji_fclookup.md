# Four Corners Lookup

Open **Tools > Four-Corner Lookup** or press `Ctrl+4` to select the **Four corner** tab. Four Corners classifies a character's visible form with four digits, read upper left, upper right, lower left, then lower right, plus an optional fifth disambiguating digit. JWPqt provides five labelled fields and a responsive diagram. The diagram is interface artwork that adapts to light or dark themes; it is not an external data source.

For each field choose a digit 0 through 9, or **Any** when you do not know that corner. The first four values match the stored four-digit classification in their displayed order. The fifth field matches its accompanying index and can distinguish characters whose primary four digits coincide. JWPqt accepts partial codes, so start with the corners you can confidently classify and add digits to reduce results. A matching character can carry a primary Four Corner code and, where metadata supplies it, a recorded alternate code. Alternate results are visibly labelled in the result tooltip rather than treated as the primary classification.

The source's legacy explanatory rules remain useful for manual classification: choose the extremal corner stroke when independent strokes compete; use the relevant handwritten block form; and use zero for a later corner occupied by a shape already counted. However, JWPqt does not calculate a Four Corner code from arbitrary rendered text. It searches factual codes from compatible extended `kanjinfo.dat`. A character with no extended record or no assigned code is not a match.

Automatic search follows the common lookup setting. Each digit change schedules a search when it is enabled. When disabled, a change removes the previous result strip until **Search** is pressed. **Clear** returns all five fields to Any and clears matches. Select results for **Information**, **Insert**, or **Copy**. Insert acts on the active document. Shift+C copies every result in order, and `I` or `F23` opens Character Information for one selected result.

The Character Information **Four Corners** value can show the primary and an available secondary code, enabling you to confirm a selection. Missing extended data is accurately unavailable, not approximated. See [SKIP Lookup](help:IDH_KANJI_SKIPLOOKUP) for pattern-code searching, [Character Information](help:IDH_KANJI_CHARINFO) for metadata display, and [Finding Kanji](help:IDH_KANJI_LOOKUP) for the shared window and result behavior.
