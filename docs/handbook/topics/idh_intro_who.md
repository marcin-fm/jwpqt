# Who Should/Should not Consider Using JWPce

JWPqt is intended for people who read, study, or write Japanese and want the older JWP document workflow together with integrated reference tools. It is particularly useful when you need to enter kana from romaji, choose kanji candidates, inspect a character, search Japanese-English dictionaries, or preserve JWP/JCE document formatting. Reading hiragana and katakana remains useful: romaji is an input method, not a replacement display alphabet.

Choose a Japanese document when compatibility with JWP/JCE files, native paragraph layout, page breaks, and the recovered Japanese editing behavior matter. Choose a plain-text document for ordinary UTF-8 or other supported text encodings. JWPqt opens and saves UTF-8, UTF-7, UTF-16, JFC, EUC-JP, Shift-JIS, New/Old/NEC JIS, and JWP/JCE formats, with loss-aware checks rather than silent substitution.

It is not a general desktop-publishing suite, collaborative cloud editor, or a promise of pixel-identical Win32 raster output. Its printing acceptance path is native PDF output and preview, not certification of every physical-printer backend. It also does not supply a browser filesystem workspace: Web users explicitly upload one local document and download saved output.

The optional historical lookup data has separate license terms and may be absent from data-free builds. Ordinary editing still works; Help > Runtime Resources identifies available components. For document formats and input choices, see [File Types](help:IDH_FILE_TYPES) and [Edit Modes](help:IDH_TEXT_EDITMODES).
