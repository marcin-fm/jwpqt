# JFC Files

JFC files are plain-text Japanese flash-card files, not native structured JWP documents. JWPqt recognizes a JFC policy through the `.jfc` extension, the JFC file-dialog filter, or an explicit `jfc` encoding selection. On opening, it prefers strict UTF-8. If that fails, it can use the recovered legacy EUC-compatible form. The compatibility fallback is strict: invalid bytes, undefined recovered code-page bytes, unmapped pairs, and incomplete sequences fail rather than being replaced with lookalike characters. See [Japanese Encoding Systems](help:IDH_FILE_ENCODING) and [Opening an Existing File](help:IDH_FILE_OPEN).

When saving a JFC document, JWPqt always writes UTF-8 without a BOM. That is intentional even if a legacy-EUC representation was used to read the file. If an EUC output is specifically required for an external legacy consumer, choose the ordinary EUC-JP text format and name the target appropriately; do not assume the JFC save policy will preserve legacy EUC bytes. The JFC policy is selected by its extension/filter/explicit encoding, while generic text-format choice is selected separately. See [Saving Files](help:IDH_FILE_SAVE) and [File Types](help:IDH_FILE_TYPES).

Because JFC is text, it does not carry native JWP paragraph formatting, hard page breaks, headers, footers, or document-summary metadata. Save As to JFC therefore follows the text-format loss protections when the current document has structured JWP data. Export Copy is useful for making a JFC derivative while retaining the original JWP document, path, baseline, and undo history. See [What is saved with a JWPce File?](help:IDH_FILE_CONTENTS).

The old association limitation described for some JFC environments is not a JWPqt file-format requirement. Use JWPqt's Open command, a drag/drop workflow on native desktop, or the appropriate explicit filter when selecting a JFC source. In the Web port, upload one local JFC file through the browser picker; successful saving downloads UTF-8 JFC bytes, not an arbitrary native filesystem rewrite.
