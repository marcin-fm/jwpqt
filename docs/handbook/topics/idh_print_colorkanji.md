# Printing and Color Kanji

JWPqt can include kanji colors in native printed/PDF output when **ColorKanji_Printing** is enabled and an active list-color mode supplies those colors. This is a captured job policy. At the moment a print or preview job is prepared, the renderer captures the document snapshot, the color list, and the applicable printing policy. Later changes to options, list membership, or editor highlighting do not alter that job's body or header/footer colors. See [Actually Printing Something](help:IDH_PRINT_PRINTING).

List colors take precedence over uncommon-kanji colors when the required list mode is active. Arbitrary rich-text colors and transient editing highlights are not copied to output. This prevents cursor selections, conversion previews, and other temporary display state from becoming misleading printed content. The policy applies to header/footer text as well as the document body when list coloring is active. If the option is disabled or no applicable list mode is active, output does not invent per-character colors from the screen. See [Headers and Footers (Page Numbering)](help:IDH_PRINT_HEADERS) and [The Header and Footer Strings](help:IDH_PRINT_HEADSTRINGS).

The color rule is independent of format preservation. Native JWP files retain their structured formatting and can use the print layout model. Text exports can require a loss confirmation because text formats cannot retain JWP layout metadata; their on-screen display should not be treated as a promise that a later imported text file retains the same print policy. See [What is saved with a JWPce File?](help:IDH_FILE_CONTENTS) and [Saving Files](help:IDH_FILE_SAVE).

Color behavior is rendered through the native desktop print/PDF pipeline. PDF text/image and preview verification are the accepted project gate; physical-printer testing is waived. The Web build has no printing or Print Preview because Qt WebAssembly lacks PrintSupport. Therefore no browser-specific Color Kanji print workflow is available in JWPqt 2.04; browser files can be downloaded and printed externally if appropriate.
