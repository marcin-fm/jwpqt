# Dictionary Support

JWPqt packages and loads dictionary and kanji resources under their original terms, separately from the GPL application. Normal 2.04 noncommercial-data packages contain unmodified EDICT, ENAMDICT, KANJIDIC-derived, radical, stroke, and related lookup payloads with their retained notices. They are not GPL program data, must not be sold or relicensed as GPL, and may require noncommercial distribution or permission for reserved uses. Configure with `-DJWPQT_BUNDLE_LEGACY_DATA=OFF` for a data-free GPL-only build. Nothing is downloaded automatically.

The normal runtime discovers packaged EDICT, ENAMDICT, `kanjinfo.dat`, `radical.dat`, `stroke.dat`, and `radicals.bmp`. A configuration directory containing `dict.cfg` or an explicit kanji resource overrides the packaged fallback. Incomplete or malformed explicit overrides fail visibly rather than mixing unrelated datasets. WNN uses its built-in system dictionary only when neither `wnn.dix` nor `wnn.dat` is present; if either external file is present, both are required. `--wnn-data-dir` can explicitly select and require another WNN directory. User learning and conversions use `user.sel` and `user.cnv` in user data; `user.dct` remains associated with `dict.cfg` unless that registry records an absolute path.

Tools > Manage Dictionaries provides staged add, edit, remove, reorder, search-policy, encoding, role, index, keep, and quiet controls. **Save and Reload** validates resources before atomically replacing the registry. Unavailable searched resources require explicit acceptance, and stale disk snapshots cannot be overwritten. ANSI registry migration asks for the original code page and writes Unicode only after a successful save. Existing lookup results and histories are preserved during configuration updates. Close an active user-dictionary editor before reload so its working copy is protected.

Runtime Resources reports loaded sources, absent components, and errors. It is the appropriate support surface for diagnosing data, rather than treating legacy utilities as everyday configuration commands. Historically, JINDEX built dictionary indexes, KINFO generated character information data, RINFO built radical/stroke data, UINFO generated Unicode conversion tables, and WINFO built conversion databases. Those tools explain the lineage of some formats but are not native JWPqt Options topics or a promise that users should run them.

For installation paths and data-free distribution, see [Support](help:IDH_SUPPORT_GENERAL). For preserved history settings that influence lookup behavior, see [Miscellaneous Options](help:IDH_OPTIONS_MISC) and [Advanced Options](help:IDH_OPTIONS_ADVANCED).
